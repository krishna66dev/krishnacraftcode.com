Getting Started with CodeIgniter 4

Installation & Project Setup

1

Install via Composer (Recommended)

CI4 requires PHP 8.0+ and Composer. Run in terminal:

composer create-project codeigniter4/appstarter myapp
2

Or Manual Download

Download the framework zip from the official site and extract to your web server root.

https://codeigniter.com/download
3

Configure .env File

Copy env to .env and update settings:

cp env .env
4

Set Base URL & Database

Edit .env — no more editing PHP config files directly. All settings live in one place.

5

Run Built-in Dev Server

CI4 ships with a built-in PHP dev server — no Apache needed locally:

php spark serve http://localhost:8080

Routing in CodeIgniter 4

Routes.php · RESTful · Filters · Spark CLI

app/Config/Routes.php CI4 WAY
$routes->get('/', 'Home::index'); $routes->get('users', 'User::index'); $routes->get('users/(:num)', 'User::show/$1'); $routes->post('users/create', 'User::create'); $routes->put('users/(:num)', 'User::update/$1'); $routes->delete('users/(:num)', 'User::delete/$1'); // Route Groups with Filter $routes->group('admin', ['filter'=>'auth'], function($routes) { $routes->get('dashboard', 'Admin\Dashboard::index'); } );
Resource Routes (RESTful Auto)
// One line = full CRUD routes! $routes->resource('users');

Filters (Middleware) — CI4 Feature
// app/Filters/AuthFilter.php namespace App\Filters; use CodeIgniter\Filters\FilterInterface; class AuthFilter implements FilterInterface { public function before($request, $args) { if (! session()->get('user_id')) { return redirect() ->to('/login'); } } }

Database, Model & Migrations

Query Builder · Entity · Migrations

CI4 Model — app/Models/UserModel.php POWERFUL
namespace App\Models; use CodeIgniter\Model; class UserModel extends Model { protected $table = 'users'; protected $primaryKey = 'id'; protected $returnType = 'array'; protected $allowedFields = ['name', 'email', 'password']; protected $useTimestamps = true; protected $validationRules = [ 'email' => 'required|valid_email', 'name' => 'required|min_length[3]' ]; }
Migration — app/Database/Migrations/
namespace App\Database\Migrations; use CodeIgniter\Database\Migration; class CreateUsersTable extends Migration { public function up() { $this->forge->addField([ 'id' => ['type'=>'INT','auto_increment'=>true], 'name' => ['type'=>'VARCHAR','constraint'=>'100'], 'email' => ['type'=>'VARCHAR','constraint'=>'150'] ]); $this->forge->createTable('users'); } public function down() { $this->forge->dropTable('users'); } }
Query Builder in Controller
$model = new UserModel(); // Fetch all / find one $users = $model->findAll(); $user = $model->find(1); // Insert with validation $model->insert([ 'name' => 'Alice', 'email' => 'alice@test.com' ]); // Update & Delete $model->update(1, ['name'=>'Bob']); $model->delete(1); // Chained query $model->where('status', 'active') ->orderBy('name', 'ASC') ->findAll();
Spark Migration Commands
# Create migration file php spark make:migration CreateUsersTable # Run all pending migrations php spark migrate # Rollback last batch php spark migrate:rollback # Seed the database php spark db:seed UserSeeder # Create a model php spark make:model UserModel

Session, Cookies & Security

CI4 Session API · Cookie Class · CSRF · Escaping

Session — CI4 Way UPDATED
// Get session service $session = session(); // Set session data $session->set([ 'user_id' => 1, 'username' => 'Alice', 'logged_in' => true ]); // Get session value $id = $session->get('user_id'); $name = $session->username; // Flashdata — show once only $session->setFlashdata('msg', 'Saved!'); $msg = $session->getFlashdata('msg'); // Remove & destroy $session->remove('username'); $session->destroy();
Cookies — CI4 Cookie Class UPDATED
use CodeIgniter\Cookie\Cookie; // Create & set a cookie (OOP) $cookie = new Cookie('theme', 'dark', [ 'expires' => '+30 days', 'samesite' => Cookie::SAMESITE_LAX, 'secure' => true ]); $this->response->setCookie($cookie); // Get & delete cookie $theme = $this->request ->getCookie('theme'); $this->response->deleteCookie('theme');
CSRF Protection — Auto in CI4
// app/Config/Security.php public $csrfProtection = 'cookie'; public $tokenName = 'csrf_test_name'; public $headerName = 'X-CSRF-TOKEN'; public $regenerate = true; // In your form — auto hidden token <?= csrf_field() ?> // For AJAX requests $token = csrf_hash(); $name = csrf_token();
Output Escaping — XSS Prevention
// In views — always escape output <?= esc($name) ?> // HTML <?= esc($url, 'url') ?> // URL <?= esc($js, 'js') ?> // JS <?= esc($css, 'css') ?> // CSS // Hash passwords $hash = password_hash( $pass, PASSWORD_DEFAULT ); password_verify($pass, $hash);
CSRF Token

Auto-regenerated per request. Use csrf_field() in every form to stay protected.

XSS via esc()

Always wrap output in esc() — context-aware escaping built in to CI4.

Secure Cookies

CI4 Cookie class supports HttpOnly, Secure, SameSite flags natively.
