Topic Explanation
Read in your preferred language

A number system is a way of representing numbers using a specific set of symbols (digits) and a base (radix). The base tells us how many unique digits the system uses.

We humans naturally use the Decimal system (Base-10) because we have 10 fingers. Computers, however, work with electricity — which is either ON (1) or OFF (0). That's why computers use the Binary system (Base-2). Every image, video, letter, or sound stored on a computer is ultimately a sequence of 0s and 1s.

Because long binary strings are hard to read, humans also use Octal (Base-8) and Hexadecimal (Base-16) as shorthand — they group binary digits more compactly. For example, the color red in HTML is written as #FF0000 — that's hexadecimal!

संख्या प्रणाली एक विशिष्ट प्रतीकों (अंकों) और आधार (Base) का उपयोग करके संख्याओं को दर्शाने का तरीका है। आधार (Base) हमें बताता है कि सिस्टम में कितने अद्वितीय अंक हैं।

हम मनुष्य स्वाभाविक रूप से दशमलव प्रणाली (Base-10) का उपयोग करते हैं क्योंकि हमारे 10 उंगलियाँ हैं। लेकिन कंप्यूटर विद्युत के साथ काम करते हैं — जो या तो चालू (1) या बंद (0) होती है। इसीलिए कंप्यूटर द्विआधारी प्रणाली (Binary, Base-2) का उपयोग करते हैं। कंप्यूटर में संग्रहीत हर चित्र, वीडियो, अक्षर या ध्वनि अंततः 0 और 1 का अनुक्रम है।

क्योंकि लंबी बाइनरी स्ट्रिंग पढ़ना कठिन है, इसलिए मनुष्य ऑक्टल (Base-8) और हेक्साडेसिमल (Base-16) का भी उपयोग करते हैं — ये बाइनरी अंकों को अधिक संक्षिप्त रूप में समूहित करते हैं। उदाहरण के लिए, HTML में लाल रंग को #FF0000 लिखते हैं — यह हेक्साडेसिमल है!

Binary System — How Computers Think
The language of all digital electronics

In binary, each digit is called a bit (binary digit). A group of 8 bits is called a byte.

The positional value of each bit is a power of 2, starting from 2⁰ on the right:

Step-by-Step Conversions
Methods with worked examples

1. Decimal → Binary (Divide by 2, collect remainders bottom-up)

Example: Convert 13 to Binary

1
13 ÷ 2 = 6, remainder 1
2
6 ÷ 2 = 3, remainder 0
3
3 ÷ 2 = 1, remainder 1
4
1 ÷ 2 = 0, remainder 1
Read remainders bottom to top: 1310 = 11012

2. Binary → Decimal (Multiply each bit by its power of 2)

Example: Convert 1101 to Decimal

→
1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = 13
11012 = 1310

3. Decimal → Hexadecimal (Divide by 16, collect remainders)

Example: Convert 255 to Hex

1
255 ÷ 16 = 15, remainder 15 = F
2
15 ÷ 16 = 0, remainder 15 = F
Read bottom to top: 25510 = FF16

4. Binary → Octal (Group binary digits in sets of 3 from right)

Example: Convert 110101 to Octal

→
110 101 → 1102=6, 1012=5 → Octal = 65
1101012 = 658
Trick: Binary → Hex: group bits in sets of 4 (each group = one hex digit). Binary → Octal: group in sets of 3.

Real-Life Examples
🎨
Website Colors — Hex in Action

Every color on a webpage is written in Hex. #FF0000 = Red (R=255, G=0, B=0). #00FF00 = Green. #0000FF = Blue. #FFFFFF = White (all 255). #000000 = Black (all 0).

🔐
Unix File Permissions — Octal

chmod 755 file — the 755 is octal. 7=111 (rwx=read+write+execute), 5=101 (r-x=read+execute). Binary groups of 3 bits map perfectly to octal — that's why it's used.

💾
Computer Memory Addresses — Hex

Memory addresses in programs are written in hex: 0x1A3F. The "0x" prefix means hexadecimal. Hex compresses what would be very long binary numbers into short, readable codes.

Key Notes — Exam Tips
Bit = smallest unit (0 or 1). Nibble = 4 bits. Byte = 8 bits. Word = 16/32/64 bits (depends on CPU).
Hex digits A=10, B=11, C=12, D=13, E=14, F=15 — must memorize for exams.
Maximum value of 8-bit (1 byte) binary = 111111112 = 25510 = FF16.
To convert Binary to Octal: group 3 bits from right. Binary to Hex: group 4 bits from right.
All computers use Binary internally. Octal and Hex are just human-readable shortcuts for binary.
The binary representation of a character is determined by ASCII (American Standard Code for Information Interchange). Example: 'A' = 6510 = 010000012.
Summary — Number Systems

Four number systems: Decimal (Base-10, digits 0–9, human use), Binary (Base-2, digits 0–1, computers), Octal (Base-8, digits 0–7, Unix permissions), Hexadecimal (Base-16, digits 0–9 and A–F, colors/memory). Conversions: Decimal→Binary: divide by 2, collect remainders bottom-up. Binary→Decimal: multiply each bit by 2 to the power of its position. Hex→Binary: each hex digit = 4 binary bits. 1 byte = 8 bits, max value = 255 = FF. ASCII maps characters to binary (A=65=01000001).

Interview / Viva Questions
Click to reveal answers
1Why do computers use Binary (Base-2) instead of Decimal (Base-10)?
Computers use binary because they are built from electronic transistors that have only two states: ON (represented as 1) and OFF (represented as 0). Binary maps perfectly to these two states, making it simple and reliable for electronic circuits to process.
2Convert 45 (decimal) to Binary.
45 ÷ 2 = 22 R 1, 22 ÷ 2 = 11 R 0, 11 ÷ 2 = 5 R 1, 5 ÷ 2 = 2 R 1, 2 ÷ 2 = 1 R 0, 1 ÷ 2 = 0 R 1. Reading remainders bottom-to-top: 45₁₀ = 101101₂
3What is the decimal value of hexadecimal 2F?
2F₁₆ = (2 × 16¹) + (F × 16⁰) = (2 × 16) + (15 × 1) = 32 + 15 = 47₁₀
4What is ASCII? Give an example.
ASCII (American Standard Code for Information Interchange) is a character encoding standard that assigns a unique number to each character. Example: 'A' = 65 = 01000001₂, 'a' = 97 = 01100001₂, '0' = 48 = 00110000₂. It uses 7 bits (128 characters).
5Convert binary 11001100 to Hexadecimal.
Group into sets of 4 bits from right: 1100 | 1100. Convert each: 1100₂ = 12₁₀ = C. So 11001100₂ = CC₁₆.
