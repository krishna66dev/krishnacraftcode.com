Topic Explanation
Read in your preferred language

An Operating System (OS) is the most important software on a computer. It acts as an interface (bridge) between the user and the hardware. Without an OS, you cannot use a computer — you would have to write machine-level code for every action.

The OS manages all hardware resources — CPU time, memory, storage, and I/O devices — and ensures that multiple programs can run at the same time without conflicts. It also provides a user interface (UI) so that people can interact with the computer easily, either through a GUI (Graphical User Interface, like Windows) or a CLI (Command Line Interface, like Linux Terminal).

Examples of popular operating systems: Windows 11 (Microsoft), macOS Ventura (Apple), Ubuntu/Kali Linux (open-source), Android (Google, for phones), iOS (Apple, for iPhone).

Types of Operating Systems
Classified by usage and working method
1. Batch Operating System
Jobs are collected in groups (batches) and processed one by one without user interaction. No real-time feedback. Used in early computers and still in payroll, bank statements.
IBM OS/360EXEC-8Bank payroll
2. Time-Sharing OS (Multitasking)
CPU time is divided into small slices (quantum) given to each user/process in turns. Gives the illusion that all users are served simultaneously. Also called Multitasking OS.
WindowsUNIXLinuxmacOS
3. Real-Time OS (RTOS)
Processes data and responds within a guaranteed time limit. Critical for systems where a delay can cause failure. Two types: Hard RTOS (strict deadlines) and Soft RTOS (flexible).
VxWorksFreeRTOSAircraft controlMedical devices
4. Distributed OS
Manages a group of independent computers that appear as one unified system to the user. Resources are shared across the network. Used in cloud computing and supercomputers.
Google Cloud OSLOCUSAmoeba
5. Multi-User OS
Allows multiple users to access the same computer system simultaneously, each with their own session. Used in mainframes, university servers, and corporate systems.
UNIXLinux ServerWindows Server
6. Mobile OS
Designed specifically for smartphones and tablets. Optimized for touch input, battery life, and mobile connectivity. App stores and notifications are key features.
Android 14iOS 17HarmonyOS
Main Functions of an Operating System
What the OS manages and controls
⚙️
1. Process Management

Creates, schedules, and terminates processes. Decides which process gets CPU time using scheduling algorithms (FCFS, Round Robin, SJF).

🧠
2. Memory Management

Allocates RAM to programs, keeps track of used/free memory, handles paging and segmentation. Prevents one process from accessing another's memory.

📁
3. File System Management

Organizes data into files and folders. Manages reading, writing, and deleting files. File systems: NTFS (Windows), ext4 (Linux), APFS (macOS).

🔌
4. Device Management

Controls I/O devices through device drivers. Manages communication between the computer and peripheral devices like printers, keyboards, and cameras.

🔐
5. Security & Protection

Provides user authentication (passwords, biometrics), access control (read/write permissions), and protects against unauthorized access and viruses.

🖥️
6. User Interface

Provides GUI (icons, windows, mouse) or CLI (text commands). GUI examples: Windows Desktop. CLI examples: Linux Terminal, Windows PowerShell.

Real-Life Examples
🏢
OS as an Office Manager

Think of the OS as the office manager of a company. The hardware (CPU, RAM, I/O) are the employees. The OS tells each employee what to do, schedules their work, ensures they don't interfere with each other, and handles communication between departments.

📱
Using Your Smartphone

When you open WhatsApp (process created → READY → RUNNING), while playing music in background (WAITING/BLOCKED), and get a notification (I/O interrupt) — your Android OS manages all of this simultaneously through multitasking and process scheduling.

✈️
Aircraft Autopilot — Real-Time OS

An aircraft autopilot uses a Hard Real-Time OS (like VxWorks). If the OS misses a deadline by even a few milliseconds — for example, adjusting a control surface during turbulence — it could be catastrophic. No delays are acceptable.

Key Notes — Exam Tips
OS is called the "System Software" — it is the first software loaded when computer starts (booting).
The process of loading OS into RAM when computer starts is called Booting. Cold Boot = power on from off; Warm Boot = restart.
Kernel is the core/heart of the OS — it directly communicates with hardware. The rest of the OS wraps around the kernel.
File systems: NTFS (Windows), ext4 (Linux), APFS (macOS), FAT32 (older, USB drives, cross-platform).
Multitasking = one CPU runs many tasks by switching rapidly. Multiprocessing = truly multiple CPUs running tasks simultaneously.
Linux is open-source (free, modifiable). Windows is proprietary (paid, source code closed). macOS is proprietary, Unix-based.
Summary — Operating System

An Operating System is system software that acts as a bridge between user and hardware. It manages: processes (scheduling: FCFS, Round Robin, SJF), memory (allocation, paging), file system (NTFS/ext4/APFS), devices (drivers), and security (authentication, permissions). Types: Batch, Time-Sharing (multitasking), Real-Time (RTOS), Distributed, Multi-User, Mobile. The Kernel is the OS core. Booting loads the OS into RAM. Examples: Windows, Linux, macOS, Android, iOS.

Interview / Viva Questions
Click to reveal answers
1What is an Operating System? What are its main functions?
An OS is system software that manages hardware and software resources, providing services to application programs. Main functions: Process management, Memory management, File system management, Device management, Security & protection, and User interface.
2What is the difference between multitasking and multiprocessing?
Multitasking: One CPU rapidly switches between multiple tasks, giving the illusion of simultaneous execution. Multiprocessing: Multiple CPUs/cores execute different processes simultaneously — true parallelism. Modern computers do both.
3What is a Kernel? What is its role?
The Kernel is the core of the OS that directly interfaces with hardware. It manages CPU scheduling, memory allocation, device drivers, and system calls. The kernel runs in privileged "kernel mode" while applications run in "user mode" for security.
4What is a Real-Time OS? Give two examples.
A Real-Time OS (RTOS) processes inputs and responds within a guaranteed time limit. Hard RTOS: strict deadlines (aircraft autopilot, medical pacemakers). Soft RTOS: deadlines important but not fatal if missed (online video streaming). Examples: VxWorks, FreeRTOS.
5List the five states of a process in an OS.
1. New – process is being created. 2. Ready – waiting to be assigned to CPU. 3. Running – currently being executed by CPU. 4. Waiting/Blocked – waiting for I/O operation to complete. 5. Terminated – process has finished execution.
