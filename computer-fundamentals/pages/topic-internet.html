Topic Explanation
Read in your preferred language

The Internet is a global network of billions of interconnected computers and devices that communicate using standardized protocols (mainly TCP/IP). It is the infrastructure. The World Wide Web (WWW) is a service that runs ON the internet — it's the collection of websites and web pages accessible through browsers.

Every website has an IP address (e.g., 142.250.182.46 for Google), but humans use domain names (google.com). The DNS (Domain Name System) translates domain names to IP addresses. Data travels via HTTP/HTTPS protocol between your browser and web servers.

Cloud Computing delivers computing resources (servers, storage, databases, networking, software) over the internet ("the cloud") on demand with pay-as-you-go pricing. Examples: AWS, Google Cloud, Microsoft Azure.

Internet Basics
Key concepts and terminology
🌐
Internet vs WWW
Internet = the physical global network infrastructure (cables, routers, servers). WWW = web pages and websites accessed via HTTP. WWW runs ON the internet. Email, FTP, and VoIP also use the internet but are NOT the web.
📍
IP Address
A unique numerical address for every device on the internet. IPv4: 32-bit, dotted decimal (192.168.1.1) — ~4.3 billion addresses. IPv6: 128-bit, hexadecimal (2001:db8::1) — 340 undecillion addresses. IPv4 exhausted; world moving to IPv6.
🏠
URL Structure
https://www.example.com:443/page?q=search#section
Protocol (https) + Subdomain (www) + Domain (example.com) + Port (443) + Path (/page) + Query (?q=search) + Fragment (#section)
🖥️
Web Server vs Browser
Web Server: computer that hosts websites and serves HTML files in response to HTTP requests (e.g., Apache, Nginx). Browser: client software that requests and renders web pages (Chrome, Firefox, Safari, Edge).
HTTP & HTTPS
How your browser talks to web servers

HTTP (HyperText Transfer Protocol) is the foundation of data communication on the web. It is a request-response protocol: your browser sends a REQUEST, the server sends a RESPONSE with the web page content. HTTPS = HTTP + SSL/TLS encryption — all data is encrypted, preventing eavesdropping.

HTTP Request-Response Flow

Step 1You type https://google.com → Browser checks DNS for Google's IP address
Step 2Browser sends HTTP GET request to Google's server (IP: 142.250.x.x) on port 443
Step 3TLS handshake — browser and server agree on encryption keys (HTTPS security)
Step 4Google's server sends HTTP 200 OK response with HTML, CSS, JavaScript files
Step 5Browser parses HTML, loads CSS/JS/images, renders the Google homepage on screen
HTTP Status Codes: 200 OK (success), 301 Moved Permanently, 404 Not Found, 403 Forbidden, 500 Internal Server Error, 503 Service Unavailable.
DNS — Domain Name System
The "phonebook" of the internet

DNS converts human-readable domain names (google.com) into machine-readable IP addresses (142.250.182.46). Without DNS, you'd need to memorize IP addresses to visit websites. DNS uses a hierarchical, distributed database of servers worldwide.

Root DNS Servers
13 root server clusters worldwide (A to M). They know the authoritative name servers for each TLD (.com, .in, .org).
TLD Name Servers
Top-Level Domain servers (.com, .in, .org). Managed by registries. Know which authoritative server has google.com's record.
Authoritative Name Server
Has the final, definitive IP record for a specific domain. Google's authoritative server returns 142.250.182.46 for google.com.
DNS Cache
Your browser, OS, and ISP cache DNS results (TTL: Time To Live) to avoid repeating lookups. Speeds up web browsing significantly.
Web Technologies — HTML, CSS, JavaScript
The three pillars of every website
🏗️
HTML
Structure & Content
Defines headings, paragraphs, links, images, tables, forms. The skeleton of every webpage. HyperText Markup Language.
🎨
CSS
Styling & Layout
Controls colors, fonts, spacing, animations, responsive layouts. The skin and clothing of a webpage. Cascading Style Sheets.
⚡
JavaScript
Interactivity & Logic
Makes pages interactive — form validation, animations, API calls, dynamic content updates without page reload (AJAX).

Cloud Computing
On-demand computing resources over the internet

Cloud computing delivers computing services (servers, storage, databases, networking, software, analytics, AI) over the internet on demand with pay-per-use pricing. Key characteristics: on-demand, broad network access, resource pooling, rapid elasticity, measured service.

🏗️
IaaS
Infrastructure as a Service
Provides virtualized computing infrastructure — servers, VMs, storage, networking. You manage OS and above. Most control, most responsibility.
Examples: AWS EC2, Google Compute Engine, Azure VMs, DigitalOcean
⚙️
PaaS
Platform as a Service
Provides a platform for developers to build, test, and deploy apps without managing underlying infrastructure. You manage only your application and data.
Examples: Heroku, Google App Engine, AWS Elastic Beanstalk, Firebase
📱
SaaS
Software as a Service
Ready-to-use software delivered over internet via browser. No installation, no maintenance. Provider manages everything. Least control, most convenience.
Examples: Gmail, Google Docs, Office 365, Zoom, Salesforce, Dropbox
Cloud Deployment Models: Public Cloud (AWS/Azure/GCP — shared infrastructure), Private Cloud (organization's own cloud), Hybrid Cloud (mix of public + private), Community Cloud (shared by organizations with common needs).

Key Notes — Exam Tips
Internet ≠ WWW: Internet is the network infrastructure; WWW is one service running on it (along with email, FTP, VoIP, etc.).
IPv4 = 32-bit (e.g., 192.168.1.1, max ~4.3 billion addresses). IPv6 = 128-bit hexadecimal (2001:db8::1, virtually unlimited). IPv4 is exhausted; IPv6 adoption growing.
ARPANET was the predecessor to the internet, developed by the US Department of Defense in 1969. Tim Berners-Lee invented the World Wide Web in 1989 at CERN.
Difference: Internet (global network), Intranet (private internal network within an organization), Extranet (intranet with limited access for select external partners).
Cloud advantages: Cost savings (no hardware purchase), Scalability (scale up/down instantly), Accessibility (anywhere/anytime), Disaster Recovery, Automatic Updates.
Bandwidth = maximum data transfer rate (Mbps/Gbps). Latency = delay in data transfer (ms). High bandwidth + low latency = fast internet experience.
Summary — Internet & Web Technologies

Internet = global TCP/IP network. WWW = websites on the internet (invented by Tim Berners-Lee, 1989). URL = Protocol + Domain + Path. DNS = converts domain names to IP addresses (port 53). HTTP (port 80) = web protocol; HTTPS (port 443) = encrypted HTTP. Status codes: 200 OK, 404 Not Found, 500 Server Error. Web = HTML (structure) + CSS (style) + JavaScript (interactivity). IPv4 = 32-bit; IPv6 = 128-bit. Cloud: IaaS (VMs — AWS EC2), PaaS (platform — Heroku), SaaS (software — Gmail). Internet protocols: HTTP, FTP, SMTP, DNS, DHCP, SSH. ARPANET = 1969 internet precursor.

Interview / Viva Questions
Click to reveal answers
1What is the difference between the Internet and the World Wide Web?
Internet: global network of billions of interconnected computers communicating via TCP/IP — the infrastructure (cables, routers, servers). WWW: a service that runs on the internet — collection of web pages and websites accessed via HTTP using browsers. The internet also supports email, FTP, VoIP, etc. — the WWW is just one of these services.
2What is DNS and how does it work?
DNS (Domain Name System) is the "phonebook" of the internet that translates domain names (google.com) to IP addresses (142.250.x.x). When you type a URL: (1) Browser checks local DNS cache, (2) Queries ISP's DNS resolver, (3) Resolver queries Root servers → TLD servers → Authoritative name servers, (4) Gets the IP and caches it. Uses UDP port 53.
3What is the difference between HTTP and HTTPS?
HTTP (HyperText Transfer Protocol, port 80): transmits web data in plain text — anyone can intercept and read it. HTTPS (HTTP Secure, port 443): HTTP + SSL/TLS encryption — all data is encrypted, authenticated, and integrity-protected. HTTPS is essential for login pages, banking, and all modern websites.
4What are IaaS, PaaS, and SaaS?
IaaS (Infrastructure as a Service): provides virtual servers, storage, networking — you manage OS and apps (e.g., AWS EC2, Azure VMs). PaaS (Platform as a Service): provides a platform to build and deploy apps — provider manages infrastructure (e.g., Heroku, Google App Engine). SaaS (Software as a Service): ready-to-use software via browser — provider manages everything (e.g., Gmail, Office 365, Zoom).
5What is the difference between IPv4 and IPv6?
IPv4: 32-bit addresses in dotted decimal (192.168.1.1), supports ~4.3 billion unique addresses — exhausted. IPv6: 128-bit addresses in hexadecimal (2001:0db8:85a3::8a2e:0370:7334), supports ~340 undecillion addresses — virtually unlimited. IPv6 also has built-in security (IPSec), better routing, and no need for NAT.
