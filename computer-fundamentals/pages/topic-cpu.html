Topic Explanation
Read in your preferred language

The CPU (Central Processing Unit) is the "brain" of a computer. Every calculation, logical decision, and instruction execution happens here. The CPU sits on the motherboard and is connected to RAM, storage, and all I/O devices through buses.

A CPU is made up of three main components: the ALU (Arithmetic Logic Unit — performs calculations), the Control Unit (CU) (manages data flow and instruction execution), and Registers (tiny ultra-fast storage inside the CPU).

The CPU works in a repeating cycle called the Fetch-Decode-Execute cycle (also called the Instruction Cycle). This cycle happens billions of times per second in modern processors — that speed is measured in GHz (Gigahertz), where 1 GHz = 1 billion cycles per second.

CPU (Central Processing Unit) कंप्यूटर का "मस्तिष्क" है। हर गणना, तार्किक निर्णय और निर्देश का निष्पादन यहाँ होता है। CPU मदरबोर्ड पर होता है और बसों (Buses) के माध्यम से RAM, स्टोरेज और सभी I/O डिवाइस से जुड़ा होता है।

CPU तीन मुख्य घटकों से बना है: ALU (अरिथमेटिक लॉजिक यूनिट — गणनाएं करता है), Control Unit (CU) (डेटा प्रवाह और निर्देश निष्पादन का प्रबंधन करता है), और Registers (CPU के अंदर अति-तीव्र छोटी मेमोरी)।

CPU एक चक्र में कार्य करता है जिसे Fetch-Decode-Execute चक्र कहते हैं। यह चक्र आधुनिक प्रोसेसर में प्रति सेकंड अरबों बार होता है। यह गति GHz (गीगाहर्ट्ज) में मापी जाती है — 1 GHz = 1 अरब चक्र प्रति सेकंड।

ALU — Arithmetic Logic Unit
The calculation engine of the CPU

The ALU performs all arithmetic and logical operations. It takes inputs from registers, performs the operation, and stores the result back in a register (typically the Accumulator).

Arithmetic Operations
Addition (+), Subtraction (−), Multiplication (×), Division (÷), Increment (++), Decrement (−−), Modulus (%)
Logical Operations
AND, OR, NOT, XOR, NAND, NOR — used for comparisons and decision making in programs
Control Unit (CU)
The manager/director of the CPU

The Control Unit does not perform calculations itself. Instead, it directs and coordinates the activities of all other components. It reads instructions from memory, decodes them, and sends signals to the ALU, registers, and memory telling them what to do.

Fetches the next instruction from RAM using the Program Counter (PC)
Decodes the instruction to determine what operation needs to be done
Sends control signals to ALU, registers, memory, and I/O devices
Manages the system bus — Data Bus, Address Bus, and Control Bus
CPU Registers
Ultra-fast temporary storage inside the CPU
Registers are the fastest storage in a computer — even faster than cache. They are built directly into the CPU chip and hold data being actively processed.

Fetch–Decode–Execute Cycle
How the CPU runs every instruction
1
FETCH
The Control Unit reads the next instruction from RAM at the address stored in the Program Counter (PC). The instruction is loaded into the Instruction Register (IR). PC is incremented to point to the next instruction.
↓
2
DECODE
The Control Unit interprets (decodes) the instruction in IR to determine what operation is needed, which operands are required, and which registers/memory locations are involved.
↓
3
EXECUTE
The ALU or other hardware unit performs the decoded operation. The result is stored in a register (Accumulator) or written back to RAM. Then the cycle repeats from step 1.
Some textbooks add a STORE step after Execute — writing results back to memory. The combined name is sometimes Fetch–Decode–Execute–Store or FDE cycle.

Key Notes — Exam Tips
CPU speed is measured in GHz. 1 GHz = 1 billion clock cycles per second. 3.5 GHz CPU can theoretically process 3.5 billion operations per second.
Word size = amount of data CPU processes in one instruction cycle. 32-bit CPU processes 32 bits; 64-bit CPU processes 64 bits (can address more RAM).
Multi-core CPU: Dual-core = 2 CPUs on one chip, Quad-core = 4, Octa-core = 8. Each core can execute instructions independently — true parallelism.
System Buses: Data Bus (carries data), Address Bus (carries memory addresses), Control Bus (carries control signals). Width of address bus determines max RAM addressable.
Intel invented the first commercial microprocessor — Intel 4004 (1971), 4-bit, 740 KHz. Modern Intel Core i9 (2024) is 24-core, 6 GHz.
Summary — CPU Architecture

The CPU has three main parts: ALU (arithmetic + logic operations), Control Unit (fetches, decodes, executes instructions), and Registers (PC, IR, ACC, MAR, MDR, SP, FLAGS — ultra-fast in-CPU storage). The CPU works in the Fetch→Decode→Execute cycle (FDE cycle). Speed is in GHz. RISC (ARM — simple instructions, low power, phones) vs CISC (x86/Intel — complex instructions, desktops). Multi-core CPUs (Dual/Quad/Octa-core) allow true parallel processing. Three buses: Data, Address, Control.

Interview / Viva Questions
Click to reveal answers
1What are the three main components of a CPU?
1. ALU (Arithmetic Logic Unit) — performs arithmetic (+, −, ×, ÷) and logical (AND, OR, NOT) operations. 2. Control Unit (CU) — fetches instructions from memory, decodes them, and controls execution. 3. Registers — small, ultra-fast storage units inside the CPU (PC, IR, ACC, MAR, MDR).
2Explain the Fetch-Decode-Execute cycle.
FETCH: CU reads the next instruction from RAM at the address in the Program Counter (PC); loads it into the Instruction Register (IR); PC increments. DECODE: CU interprets the instruction in IR. EXECUTE: ALU or other unit performs the operation; result stored in Accumulator or RAM. Cycle repeats.
3What is the role of the Program Counter (PC)?
The Program Counter (PC) is a register that holds the memory address of the next instruction to be fetched from RAM. After each fetch, the PC is automatically incremented to point to the next instruction, keeping track of program execution sequence.
4What is the difference between RISC and CISC?
RISC (Reduced Instruction Set Computer): few simple instructions, 1 cycle per instruction, low power, fast — used in smartphones (ARM processors, Apple M1/M2). CISC (Complex Instruction Set Computer): many complex instructions, multiple cycles per instruction, higher power — used in desktops/laptops (Intel x86, AMD).
5What are the three types of system buses?
1. Data Bus: carries actual data between CPU, RAM, and I/O devices. Width (8/16/32/64-bit) determines how much data is transferred per cycle. 2. Address Bus: carries memory addresses — its width determines the maximum RAM the CPU can address. 3. Control Bus: carries control signals (read, write, interrupt) from the Control Unit.
