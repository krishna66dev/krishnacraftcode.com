Topic Explanation
Read in your preferred language

Cyber Security is the practice of protecting computers, servers, mobile devices, networks, and data from digital attacks, unauthorized access, damage, or theft. As the world becomes more connected, cyber threats are one of the biggest risks facing governments, businesses, and individuals.

The foundation of cyber security is the CIA Triad: Confidentiality (only authorized people can access data), Integrity (data is accurate and unaltered), and Availability (systems are accessible when needed). Every security measure exists to protect one or more of these three properties.

Key areas include: threat prevention (firewalls, antivirus), detection (IDS/IPS), encryption (protecting data in transit and at rest), authentication (passwords, 2FA, biometrics), and incident response. India's nodal cyber security agency is CERT-In (Indian Computer Emergency Response Team).

साइबर सुरक्षा कंप्यूटर, सर्वर, मोबाइल डिवाइस, नेटवर्क और डेटा को डिजिटल हमलों, अनधिकृत पहुंच, क्षति या चोरी से बचाने का अभ्यास है। जैसे-जैसे दुनिया अधिक जुड़ी होती जा रही है, साइबर खतरे सरकारों, व्यवसायों और व्यक्तियों के लिए सबसे बड़े जोखिमों में से एक हैं।

साइबर सुरक्षा की नींव CIA त्रय है: गोपनीयता (केवल अधिकृत लोग डेटा तक पहुंच सकते हैं), अखंडता (डेटा सटीक और अपरिवर्तित है), और उपलब्धता (जरूरत पड़ने पर सिस्टम सुलभ है)। भारत की नोडल साइबर सुरक्षा एजेंसी CERT-In है।

The CIA Triad — Core Security Goals
Every security control protects one or more of these
🔒
Confidentiality
Only authorized users can access sensitive data. Achieved through: encryption, access controls, passwords, authentication, and need-to-know policies.
Violated by: data breaches, unauthorized access, eavesdropping
✅
Integrity
Data is accurate, complete, and unaltered. Only authorized users can modify it. Achieved through: hashing, digital signatures, checksums, audit logs.
Violated by: man-in-the-middle attacks, data tampering, SQL injection
⚡
Availability
Systems, services, and data are accessible to authorized users when needed. Achieved through: redundancy, backups, DDoS protection, load balancing, disaster recovery.
Violated by: DDoS attacks, hardware failure, ransomware
Common Cyber Threats
Know your enemy to defend against it
🦠
Malware
Malicious software designed to harm, disrupt, or gain unauthorized access. Umbrella term covering: Virus (attaches to files, spreads), Worm (self-replicates across network), Trojan (disguised as legitimate software), Spyware (steals data silently), Adware (unwanted ads).
🛡️ Prevention: Antivirus, OS updates, avoid unknown downloads
🎣
Phishing
Fraudulent emails/messages/websites that trick users into revealing credentials, personal info, or installing malware. Spear phishing = targeted at specific individuals. Smishing = via SMS. Vishing = via voice call. One of the most common attack vectors worldwide.
🛡️ Prevention: Check sender email carefully, never click suspicious links, use 2FA
🔐
Ransomware
Malware that encrypts the victim's files and demands a ransom (usually cryptocurrency) for the decryption key. Famous attacks: WannaCry (2017, affected 230,000 computers), Petya/NotPetya (2017). Can cripple hospitals, governments, and businesses.
🛡️ Prevention: Regular offline backups, patched OS, email filtering
💥
DDoS Attack
Distributed Denial of Service — floods a server/network with massive traffic from thousands of compromised devices (botnet) until it crashes and becomes unavailable to legitimate users. Violates Availability.
🛡️ Prevention: CDN, rate limiting, DDoS protection services (Cloudflare)
🕵️
Man-in-the-Middle (MitM)
Attacker secretly intercepts and potentially alters communication between two parties who think they are communicating directly. Example: Attacker on public Wi-Fi intercepts your login credentials. Violates both Confidentiality and Integrity.
🛡️ Prevention: HTTPS, VPN, avoid unsecured public Wi-Fi
💉
SQL Injection
Attacker inserts malicious SQL code into a web form input to manipulate the backend database — bypass login, steal data, drop tables. Example: entering ' OR '1'='1 as username to bypass authentication.
🛡️ Prevention: Parameterized queries, prepared statements, input validation
🌐
XSS — Cross-Site Scripting
Attacker injects malicious JavaScript into a trusted website that executes in victims' browsers — can steal cookies, session tokens, redirect users. Very common in web apps.
🛡️ Prevention: Input sanitization, Content Security Policy (CSP) headers, output encoding

🔑 Symmetric Encryption
Same key for encrypt & decrypt
One secret key shared between sender and receiver. Very fast — suitable for encrypting large amounts of data. Problem: securely sharing the key.
Algorithms: AES (Advanced Encryption Standard — most widely used), DES (old), 3DES, RC4
🔑🔓 Asymmetric Encryption
Public key + Private key pair
Two mathematically linked keys: Public key (anyone can use to encrypt) and Private key (only owner uses to decrypt). Solves key distribution problem. Slower than symmetric.
Algorithms: RSA (most common), ECC (Elliptic Curve), DSA. Used in: SSL/TLS, digital signatures, HTTPS
Hashing is NOT encryption — it is a one-way function (MD5, SHA-256) that converts data into a fixed-size digest. Used for password storage, file integrity checks. Cannot be reversed.
Firewall, IDS & IPS
Your network's security gatekeepers
🧱
Firewall

A network security device (hardware or software) that monitors and filters incoming/outgoing network traffic based on predefined security rules (ACL — Access Control List). Acts as a barrier between trusted internal network and untrusted external networks. Types: Packet Filter, Stateful Inspection, Application-Layer (WAF — Web Application Firewall), Next-Gen Firewall (NGFW).

🔍
IDS — Intrusion Detection System

Monitors network traffic for suspicious activity and known attack patterns, then alerts administrators. Passive — detects and reports but does NOT block traffic automatically. Signature-based (known threats) or anomaly-based (deviation from baseline).

🛡️
IPS — Intrusion Prevention System

Like IDS but active — it detects AND automatically blocks malicious traffic in real time. Sits inline in the network path. Can drop packets, reset connections, and block IP addresses. More advanced than a firewall alone.

🌐
VPN — Virtual Private Network

Creates an encrypted "tunnel" over the internet, allowing secure remote access to a private network. Hides your IP address and encrypts all traffic. Uses protocols: OpenVPN, IPSec, WireGuard. Used by: corporate remote workers, privacy-conscious users, bypassing geo-restrictions.

Ethical Hacking & Hacker Types
Using hacking skills for defence
⚪
White Hat Hacker
Ethical hackers. Use hacking skills with permission to find vulnerabilities and improve security. Also called Penetration Testers. CEH (Certified Ethical Hacker) certified professionals.
⚫
Black Hat Hacker
Malicious hackers. Break into systems without permission for personal gain, data theft, disruption, or financial fraud. Criminal activity — illegal worldwide.
🩶
Grey Hat Hacker
Between white and black hat. May hack without permission but reports the vulnerability to the owner (sometimes for a fee). Intent is not purely malicious but still unauthorized.
Penetration Testing (Pen Test) phases: Reconnaissance → Scanning → Gaining Access → Maintaining Access → Covering Tracks. Tools: Kali Linux, Metasploit, Nmap, Wireshark, Burp Suite.
Cyber Security Best Practices
Essential habits for everyone
Strong Passwords: Min 12 chars, mix of uppercase, lowercase, numbers, symbols. Never reuse passwords. Use a Password Manager (Bitwarden, 1Password).
Two-Factor Authentication (2FA): Even if password is stolen, attacker needs a second factor (OTP, authenticator app). Enable on all important accounts.
Regular Backups: Follow 3-2-1 rule: 3 copies, 2 different media, 1 offsite/cloud. Protects against ransomware and hardware failure.
Keep Software Updated: OS, browser, apps — patches fix known vulnerabilities. Enable auto-updates. Outdated software = open door for attackers.
Email Safety: Never click suspicious links. Verify sender identity. Attachments can contain malware. Legitimate organizations never ask for passwords via email.
Avoid Public Wi-Fi for sensitive tasks. Use a VPN if necessary. Attackers can set up evil twin hotspots with the same name as a legitimate network.
Key Notes — Exam Tips
CIA Triad: Confidentiality + Integrity + Availability — the three core security goals. DAD (Disclosure, Alteration, Denial) is the opposite/threat.
AES (Advanced Encryption Standard) = most widely used symmetric encryption. Key sizes: 128, 192, 256 bits. Replaced DES (broken).
RSA = most common asymmetric algorithm. Based on difficulty of factoring large prime numbers. Used in HTTPS, digital certificates, SSH.
SSL/TLS: SSL is old/deprecated; TLS (1.2, 1.3) is current. Both provide HTTPS encryption. TLS 1.3 is the latest and most secure.
India's IT Act: IT Act 2000 (and 2008 amendment) — governs cyber crimes in India. Section 66 (hacking), Section 67 (obscene material), Section 43 (damage to computers).
Social Engineering = manipulating humans (not computers) to gain unauthorized access. Most common form = Phishing. "The human is always the weakest link."
Summary — Cyber Security

CIA Triad: Confidentiality (encryption, access control), Integrity (hashing, digital signatures), Availability (backups, DDoS protection). Threats: Malware (virus/worm/trojan), Phishing (fake emails), Ransomware (encrypts files for ransom), DDoS (overwhelms server), MitM (intercepts communication), SQL Injection, XSS. Encryption: Symmetric (AES — one key, fast), Asymmetric (RSA — public+private key pair, HTTPS). Hashing: MD5, SHA-256 (one-way, cannot decrypt). Firewall (filters traffic), IDS (detects, alerts), IPS (detects + blocks), VPN (encrypted tunnel). Hacker types: White hat (ethical), Black hat (malicious), Grey hat. India's IT Act 2000 governs cybercrime.

1What is the CIA Triad in cyber security?
CIA Triad = Confidentiality (only authorized users access data — via encryption, passwords), Integrity (data is accurate and unaltered — via hashing, digital signatures), Availability (systems accessible when needed — via backups, redundancy, DDoS protection). Every security control protects one or more of these three properties.
2What is the difference between symmetric and asymmetric encryption?
Symmetric: one shared secret key used for both encryption and decryption. Fast, good for bulk data. Problem: securely sharing the key. Algorithm: AES. Asymmetric: a key pair — public key (anyone can encrypt) + private key (only owner decrypts). Solves key sharing problem. Slower. Algorithm: RSA. Used in HTTPS, digital signatures, SSL/TLS.
3What is a firewall and how does it differ from an IDS?
Firewall: network security device that monitors and filters traffic based on rules (ACL) — blocks or allows traffic. Preventive. IDS (Intrusion Detection System): monitors traffic for suspicious patterns and ALERTS administrators — passive, does not block. IPS (Intrusion Prevention System): like IDS but actively blocks threats in real time. Firewall = gatekeeper; IDS = alarm; IPS = security guard.
4What is phishing? How is it different from spear phishing?
Phishing: mass fraudulent emails/messages impersonating legitimate organizations to trick users into revealing credentials or installing malware. Spear Phishing: targeted phishing attack aimed at a specific individual or organization using personalized information — much more convincing and dangerous. Other variants: Smishing (SMS), Vishing (voice calls), Whaling (targets executives).
5What is the difference between hashing and encryption?
Encryption: two-way process — data can be encrypted (with key) and decrypted (with key). Designed for data confidentiality during transmission. Algorithms: AES, RSA. Hashing: one-way function — converts data to a fixed-size digest (hash). Cannot be reversed. Used for password storage and file integrity verification. Algorithms: MD5 (broken), SHA-256, SHA-3.
