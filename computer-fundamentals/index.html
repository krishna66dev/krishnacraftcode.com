Computer Fundamentals
Curriculum

Tap any card to dive deep into the topic with full explanations, examples and quizzes.

Basic Level
What is a Computer?

Understand the definition, history and basic working of a computer. Learn IPO Cycle — Input, Process, Output.

Basic
Hardware vs Software

Explore the difference between physical components (Hardware) and programs (Software). Types, examples, and real-life comparisons.

Basic
Input & Output Devices

Keyboard, Mouse, Scanner, Monitor, Printer — learn which devices take information IN and which give information OUT.

Basic
Intermediate Level
Memory: RAM & ROM

Primary memory types, volatile vs non-volatile, memory hierarchy, cache levels, DRAM vs SRAM, BIOS, and EEPROM — with real-life analogies.

Intermediate
Storage Devices

HDD, SSD, Pen Drive, CD/DVD, Blu-ray — secondary storage with speed & capacity comparisons, NVMe vs SATA, and optical disc types.

Intermediate
Number Systems

Binary, Decimal, Octal & Hexadecimal — step-by-step conversions, ASCII encoding, and a live interactive number converter tool.

Intermediate
Advanced Level
Operating System

OS types (Batch, Real-Time, Distributed), functions, process states, CPU scheduling algorithms, file systems, and kernel explained.

Advanced
CPU Architecture

ALU, Control Unit, registers (PC, IR, ACC, MAR), Fetch-Decode-Execute cycle, clock speed in GHz, RISC vs CISC, and multi-core processors.

Advanced
Computer Generations

All 5 generations with technologies, examples, speed units, and timeline — from ENIAC vacuum tubes to AI and ULSI. Includes Moore's Law.

Advanced
Computer Networks

LAN, WAN, MAN, PAN — network types, topologies (Bus, Star, Ring, Mesh), OSI 7-layer model, TCP/IP model, and networking devices.

Advanced
Database Fundamentals

DBMS, RDBMS, tables, primary & foreign keys, SQL queries, normalization (1NF–3NF), ER diagrams, and RDBMS vs NoSQL comparison.

Advanced
Software Engineering

SDLC phases, Waterfall vs Agile vs Spiral models, software testing (Black Box, White Box, UAT, Regression), SRS, and DevOps basics.

Advanced
Internet & Web Technologies

HTTP/HTTPS, DNS, IP addressing (IPv4/IPv6), HTML/CSS/JavaScript basics, cloud computing (IaaS/PaaS/SaaS), and key internet protocols.

Advanced
Cyber Security

CIA triad, malware, phishing, ransomware, DDoS, encryption (AES/RSA), firewall, IDS/IPS, VPN, ethical hacking, and India's IT Act 2000.
